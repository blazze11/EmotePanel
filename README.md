# EmotePanel for WoW: Forever

An eight-slot wheel for controller and mouse. Keep spells, items, macros, quick chat, and game shortcuts together. Customize Categories and Favorites, mark targets, send group pings, or use a separate Pet Wheel on Hunters and Warlocks.

Each character gets a profile named **Firstname Lastname**. Use **Profiles** in
Settings to switch setups or share selected settings and entries. **Default** is
the fresh-install preset. Upgrades retain existing characters’ setups. Use the
profile dropdown to review wheel keys that conflict with other WoW actions. The
Settings title bar shows the active profile and addon version.
Use `/ep reset` to confirm restoring the active profile to addon defaults.

## Get started

1. Download the Forever ZIP and extract `EmotePanel` into `World of Warcraft/_forever_/Interface/AddOns/`. [GitHub Releases](https://github.com/blazze11/EmotePanel/releases) · [CurseForge](https://www.curseforge.com/wow/addons/emote-panel/files)
2. Type `/ep setup` and press a key or controller button for the main wheel. Use **Wheel Keybinds** in **Help → Start Here** to reach the main and Pet Wheel keybinds in General.
3. Use your assigned keybind to open the wheel. Open **Actions** in Settings to add spells, items, and macros.
